# 💫 About Me:
Hi, I’m Varsha Jaiswal — a software engineer passionate about building scalable products and cloud-native systems, with experience across AWS, GCP, Kubernetes, and serverless architectures. I enjoy working at the intersection of Software Engineering, Platform reliability, and Machine Learning systems.<br><br>I’ve led and shipped impactful features for large-scale merchant and SaaS platforms, designed microservices, and built resilient CI/CD automation using GitHub Actions & Docker.
